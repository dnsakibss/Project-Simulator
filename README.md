## 🔑 About CivicLens

**CivicLens** is a civic complaint management platform designed to:

- Allow citizens to **submit complaints** about public issues
- Enable **admins** to manage, assign, and resolve complaints
- Support **location-based** complaint tracking
- Provide a structured **approval workflow**
- Manage **user roles** across the system
